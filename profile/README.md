# StrixMCS Labs

`StrixMCS Labs · Dr. Matt Booth`

StrixMCS Labs is the publishing imprint of StrixMCS. It issues the apps, tools and research that leave the home and go public on GitHub. Each project keeps its own plain name; Labs is the publisher. The systems that run the home stay under StrixMCS and are not published here.
